# Lunaria - Privacy-First Women's Wellness App - architecture

A Flutter application built so that sensitive data does not need to leave the device to be useful. Feature-first architecture keeps each domain self-contained, and the design system is specified through screen and component contracts so behaviour stays consistent as the app grows.

## Components

### Feature modules

Self-contained domains with their own entities and screens

### Domain layer

Entities and rules independent of UI

### Design contracts

Screen and component specifications driving implementation

### Local persistence

On-device storage for sensitive records

## Stack

| Layer | Technology |
| --- | --- |
| Framework | Flutter |
| Language | Dart |
