# Lunaria - Privacy-First Women's Wellness App - case study

**Engineer:** Muhammad Tanveer - Full-Stack AI Automation Engineer  
**Repository:** https://github.com/haddindeve/lunaria-womens-wellness-app

## Context

Cycle-tracking apps routinely send intimate health data to third-party servers and advertising SDKs. Users who want the tracking often do not want the data collection that normally comes with it.

## What I built

A Flutter application built so that sensitive data does not need to leave the device to be useful. Feature-first architecture keeps each domain self-contained, and the design system is specified through screen and component contracts so behaviour stays consistent as the app grows.

## Capabilities delivered

- Cycle and symptom tracking
- Privacy-first data handling
- Feature-first modular architecture
- Documented design system contracts
- Light and dark presentation

## Outcome

- Sensitive health data kept on-device by design rather than by policy
- Design contracts allow UI changes without redesigning each screen from scratch
